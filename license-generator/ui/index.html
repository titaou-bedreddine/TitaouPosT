🔑 TitaouPOS License Generator

Developer tool — sign licenses bound to each client PC. Keys are Ed25519-minisign signed; clients verify with the public key embedded in the POS build.

1 · MASTER KEY checking…

The secret key signs every license — keep %APPDATA%\TitaouPosT\license_master.key private (back it up; never commit it).

2 · SIGN A LICENSE

.lic file is preferred by the client (drag-and-drop). Publishing enables one-click online activation.

3 · REVOCATION (GitHub registry)

A revoked machine goes READ-ONLY in every TitaouPOS within ~30 minutes (or at its next activation attempt) — the serial can never be reused on another PC.
